# MVCCartelera

Aplicación ASP.NET Core MVC para administrar una cartelera de cine mediante operaciones CRUD de películas y salas, conectada a SQL Server.

## Grupo

5L1

## Base de datos

- `Cartelera5L1`
- `Movies5L1`
- `Salas5L1`

Consulta `database/Cartelera5L1.sql` para crear la base de datos. Revisa `docs/INSTALACION.md` para configurar y ejecutar el proyecto.
